# Enums and Composition in Java

In this module, I studied how to use enumerations and composition in Java to model real-world problems in an object-oriented way.

The focus was on improving code organization, readability, and responsibility distribution between classes.

## Topics Covered
- Enumerations (`enum`)
- Converting strings to enum values
- Advantages of enums (better semantics and compiler support)
- Class categories (Entities, Services, Controllers, Repositories)
- Composition ("has-a" and "has-many" relationships)
- Responsibility delegation between objects
- Basic UML representation

## Key Concepts
- Enums are used to represent a fixed set of related constants (e.g. order status).
- Composition allows an object to contain other objects, representing real-world relationships.
- Composition improves code organization, cohesion, and reuse.
- Each class should be responsible for its own data and behavior.

## Practice Exercises
- Worker with multiple contracts and monthly income calculation (composition-excfix)
- Social media post with comments using composition and `StringBuilder`
- Order system with client, items, products and order status using enums and composition

All exercises were implemented using classes, enums and object composition to apply the studied concepts in practical scenarios.
